発展：レポートに貼れる図の作り方

ノートこの資料について

これは 発展 であり，必修ではない．取り組むかは自由で，成績の素点には含めない． 第4回までの道具（ベクトル・ブロードキャスト・for・対数軸）だけで読める．

本編では「値が見えるか」を優先して，体裁には手を入れてこなかった． ここでは 他人に見せる図 にするための指定をまとめる． 月刊レポートや卒論で図を貼るときに，ここへ戻ってくればよい．

ファイルの保存先の話は 発展：ファイルとパス にある． この資料の最後で savefig を使うので，先にそちらを読んでおくとよい．

ノートこの資料のキーワード
  • 体裁は default() で一度決める．図ごとに書き足さない．
  • 測った点は scatter，理屈の曲線は plot．重ねて見せるのがレポートの型．
  • 図の中の文字は 英語で書く（理由は最後の節）．
  • 保存は savefig．ただし 貼り方を間違えると提出物から図が消える．

体裁を一度決める：default

レポートに何枚も図を貼るとき，図ごとに体裁を書くと揃わない． default() を一度呼べば，以降のすべての図に効く．

using Plots

default(size=(640, 420),      # figure size in pixels
        dpi=200,              # resolution when saved to a file
        framestyle=:box,      # draw a frame on all four sides
        grid=true,            # show grid lines
        legend=:topleft,      # where to put the legend
        linewidth=2,          # thicker lines are easier to read in print
        markersize=5,
        label="")             # no legend entry unless we ask for one

dpi は保存したときの細かさである．画面で見るぶんには既定値で足りるが， 紙に印刷したり，Word に貼って拡大すると粗さが見える．dpi=200 くらいにしておくと安心である．

重要予測しよう（L1）

default で label="" としたので，次のセルの図に凡例は出るだろうか． plot の側で label="sin" と書いてある．どちらが効くか，実行する前に考えよう．

x = range(0, 2π, length=200)

p = plot(x, sin.(x), label="sin", xlabel="x", ylabel="y", title="trig functions")
plot!(p, x, cos.(x), label="cos", linestyle=:dash)

その図で書いた指定が勝つ．default は「書かなかったときの値」を決めるだけである． だから default で全体をそろえ，必要な図だけ上書きする，という使い方になる．

xlabel・ylabel・title は 軸が何を表すか を読み手に伝える． レポートの図では，軸の名前と単位を必ず書く（xlabel="time (s)" のように）．

測った点と，理屈の曲線を重ねる

レポートでいちばんよく描くのは，実験で測った点と，式から計算した曲線を重ねた図である．

  • 測った点 … scatter（点だけを打つ）
  • 式の曲線 … plot（点をつなぐ）
xd = [0.5, 1.2, 2.0, 3.1, 4.0, 5.2]        # measured points
yd = [0.6, 0.9, 0.8, 0.1, -0.7, -0.9]

q = scatter(xd, yd, label="measured", marker=:circle, color=:black,
            xlabel="x", ylabel="y", title="data and model")
plot!(q, x, sin.(x), label="model: sin x", color=:red)

点と線を 見た目で区別する のが要点である． 測定点は黒の丸，モデルは赤の実線にした．白黒で印刷されても区別がつく組み合わせを選ぶとよい．

よく使う指定を並べておく．

指定 書き方の例
線の種類 linestyle=:solid :dash :dot :dashdot
線の色 color=:red :blue :black color=RGB(0.2,0.4,0.8)
点の形 marker=:circle :square :utriangle :diamond :xcross
点の大きさ markersize=6
凡例の位置 legend=:topleft :bottomright :outertopright legend=false
軸の範囲 xlims=(0, 6) ylims=(-1.2, 1.2)

図を2つ並べる：サブプロット

plot が返す値は 図そのもの である．変数に入れておけば，あとで並べられる．

第4回で見た「線形軸と対数軸で同じデータを見比べる」のような場面で効く．

p1 = plot(x, exp.(x), title="linear axis", xlabel="x", ylabel="exp(x)")
p2 = plot(x, exp.(x), yscale=:log10, title="semi-log", xlabel="x", ylabel="exp(x)")

plot(p1, p2, layout=(1, 2), size=(900, 350))     # 1 row, 2 columns

layout=(1, 2) は 1行2列 である．縦に並べたいなら (2, 1) にする． 並べると図が細くなるので，size を横に広げておく．

ノートなぜ変数に入れるのか

plot! は「直前の図に描き足す」命令である．図が1枚のときはそれで困らないが， 2枚を交互に作ると，どちらに描き足されたか分からなくなる． plot!(p1, ...) のように 図を名前で指定する と，取り違えが起きない．

注釈を入れる

図の中の特定の場所に説明を書き込むには annotate! を使う． 目印の線を引くには hline!（横線）と vline!（縦線）を使う．

r = plot(x, sin.(x), label="sin", xlabel="x", ylabel="y")
hline!(r, [0], color=:gray, linestyle=:dot, label="")       # mark y = 0
vline!(r, [π], color=:gray, linestyle=:dot, label="")       # mark x = pi
annotate!(r, π/2, 1.0, text("peak", 10, :left, :bottom))    # text at (pi/2, 1)

text("peak", 10, :left, :bottom) の 10 は文字の大きさ， :left・:bottom は 指定した座標が文字のどこに来るか である． :left, :bottom なら，座標が文字の左下になる（つまり文字は右上へ伸びる）．

図をファイルに保存する

Word や PowerPoint に貼るには，図をファイルに書き出す．savefig を使う．

保存先は いま居る場所 である（発展：ファイルとパス）． どこに出来たか分からなくなるので，先に pwd() を見る．

pwd()                                   # where will the file go?
"/Users/hs/Documents/__Class/26w-MSE-prog/memoProgClass2026w-work"
savefig(r, "report-fig.png")            # save the figure r
isfile("report-fig.png")                # did it get written?
true

拡張子で形式が決まる．用途で選ぶ．

拡張子 向き 備考
.png Word・PowerPoint に貼る dpi が効く．いちばん無難
.pdf LaTeX に貼る．印刷 拡大しても粗くならない（ベクタ形式）
.svg web に置く 同じくベクタ形式 
for ext in ("png", "pdf", "svg")        # compare the file sizes
    savefig(r, "report-fig." * ext)
    println(ext, ": ", filesize("report-fig." * ext), " bytes")
end
png: 54482 bytes
pdf: 6942 bytes
svg: 32028 bytes

.pdf が小さいのは，点の色を並べるのではなく「線を引け」という指示を書いているからである． 写真のような絵には向かないが，グラフにはこの形式が向いている．

警告落とし穴の例：提出した HTML から図が消える

savefig で作った PNG を，Markdown セルから次のように貼りたくなる．

![](report-fig.png)

これをやると，notebook を HTML で保存して提出したとき，図が表示されない． HTML の中には「report-fig.png を見に行け」という指示だけが残り， PNG そのものは埋め込まれないからである．提出するのは HTML 1枚なので，画像が行方不明になる．

セルの出力として表示された図は，HTML の中に埋め込まれる． だから提出する notebook では，plot の結果をそのままセルに出すこと． savefig した PNG は，Word や PowerPoint に貼るためのものと考えればよい．

図の中の文字は英語で書く

この教材の図は，題・軸ラベル・凡例・注釈をすべて英語にしている． 説明したいことは，図ではなく Markdown セルの文章 に日本語で書く．

図に漢字を入れると，エラーが出ないまま豆腐（□）になることがある． 提出したあとで気付くことになるので，はじめから英語にしておく．

ノートどうしても図に日本語を入れたいとき

日本語のフォントを別に用意して登録すれば表示できる． ただし フォントのファイルを一緒に配る必要があり，環境によって手順が変わるので， この教材では採らない．やってみたい人は次を参照．

  • GR へのフォント登録の解説：https://ujimushisradjp.hatenablog.jp/entry/2025/01/17/222826
  • IPAex フォント（配布元）：https://moji.or.jp/ipafont/

なお，レポート本文が日本語でも，図の中だけ英語という体裁は珍しくない． 学術論文では普通のことなので，恥ずかしがる必要はない．

この資料で扱わなかったこと

  • アニメーション（@animate・gif）… 生成に時間がかかり，ファイルが大きく， 表示が環境に依存する．レポートに貼れる形でもないので，この教材では扱わない．
  • 自分の描画関数を作る（同じ体裁の図を何枚も作るとき）… 関数の定義は第7回で学ぶ．そこまで進んだら， default() だけでなく「図を描く手順そのもの」を関数にまとめられる．

まとめ

  • 体裁は default() で一度決める．図ごとの指定が 勝つ（default は既定値だけ）．
  • レポートの図には 軸の名前と単位を書く（xlabel="time (s)"）．
  • dpi は保存したときの細かさ．印刷や拡大を考えて dpi=200 くらいにする．
  • 測った点は scatter，式の曲線は plot．白黒でも区別がつく色と形を選ぶ．
  • plot が返す値は 図そのもの．変数に入れて plot(p1, p2, layout=(1,2)) で並べる．
  • plot!(p1, ...) と 図を名前で指定すると，描き足す先を取り違えない．
  • 注釈は annotate!，目印の線は hline!／vline!．
  • 保存は savefig．保存先は pwd() の場所（発展：ファイルとパス）． 拡張子で形式が決まる：.png は Word 向け，.pdf と .svg は拡大に強い．
  • 落とし穴：savefig した PNG を ![](fig.png) で貼ると， HTML で提出したとき図が消える．提出する notebook では セルの出力として図を出す．
  • 図の中の文字は英語．漢字は Markdown セルの文章に書く．
