はじめに

大学1年次向け プログラミング演習 の教材である（2026年度版）． 言語は Julia 1.12，作図は Plots.jl（GRバックエンド） を使う．

題材は，大学初年級の数学と工学に現れる計算から選んである． プログラミングを「道具」として，数式やアルゴリズムが計算機の上でどう振る舞うかを確かめていく．

この教材の学び方

実行する前に，結果を予測する． 各回には「予測しよう」という印が何度も現れる． そこでは，セルを動かす前に答えを書き出す．そのうえで実行し，予測と照らし合わせる． 予測が外れたときが，いちばん学べる瞬間である．

照合の基準は，回が進むにつれて強くなる．

  • L1：自分の手計算と照らし合わせる（第1回から）
  • L2：既知の公式，厳密解，特殊値と照らし合わせる（第3回から）
  • L3：もっともらしく見える結果を，独立した基準（不変量，誤差の減り方，理論との食い違い）で検証する（第10回から）

生成AIは数秒でコードを書く．だから，書く力と同じだけ，確かめる力が要る． この教材が全体として目指すのは，その確かめ方である．

落とし穴．各回に，結果が直感に反する例を置いてある． どれも，その回までに学んだ概念だけで理由を説明できる． 予想が外れたときこそ，何が起きているかを確かめる機会である．

みんなで考えよう．各回の最後に，答えを配らない問題がある． 近くの人と話し合い，考えたことを書き留める． その場で解ききれなくてよい．後の回で学ぶ道具が，解き方になることもある．

Julia言語について

この教材は Julia を使う． Julia は，書きやすさと実行の速さの両立を目指して作られた言語である． どんな目的にも使える汎用の言語だが，数値計算の扱いにとくに優れている．

数式に近い形で書けるので，紙の上の式と，計算機に書いた式を見比べやすい． この教材が「数式が計算機の上でどう振る舞うか」を主題にできるのは，そのためである．

プログラミングの演習が，言語の習得に留まらず， 数学・技術・工学の理解の助けになることを願っている．

バージョン

Julia の 1.0 版は2018年8月に公開された． 以降は 上位互換性が保たれているので，この教材のコードは後のバージョンでも動く見込みである． 新しい版のほうが速いことも多いので，自分のPCに入れるなら新しいものを選んでよい．

調べ方

検索するときは Julialang という語を使う． Julia の1語で検索すると，人の名前として使われることが多いため，目的の情報にたどり着きにくい．

公式のドキュメントには，日本語訳がある．

  • Julia Documentation（本家．英語）
  • Julia 1.12 Documentation 非公式日本語訳 （この教材が使う Julia 1.12 に対応している）

各回の「今回のまとめ」には，その回で使った関数へのリンクを並べてある． 分からない関数が出てきたら，まずそこから引くとよい．

動作環境

  • Julia 1.12 以上
  • Plots（GRバックエンド）．第9回のみ SpecialFunctions も使う
  • notebook の先頭セルが，足りないパッケージをその場で導入する

もっと知りたくなったときの入口は さらに学ぶために にまとめてある．

各回の内容

第I部　命令型の素地

第1回 変数・代入・再代入．変数は「箱」ではなく「名札」
第2回 ベクトルと基本プロット．全部を変換するならブロードキャスト，一部を選ぶなら添字
第3回 for文と総和．パラメータを変えて曲線を重ねる

第II部　数理題材と概念の拡張

第4回 対数グラフで直線化する．べき乗則は両対数，指数則は片対数で直線になる
第5回 平面図形の変形．平行移動，伸縮，回転
第6回 条件分岐．はさみうち法を手で回してみる
第7回 関数定義の初歩．はさみうちの1ステップを関数にする

第III部　数値・配列操作・抽象化

第8回 配列の生成と要素代入．エラトステネスの篩
第9回 整数は有限のビット世界．剰余演算とユークリッド互除法
第10回 浮動小数点は有限の有効数字．桁落ちと情報落ち
第11回 復習．落とし穴の理由を，自分のことばで言う
第12回 反復の設計．収束の打ち切りと数値積分
第13回 関数の作り込み．既定値，複数戻り値，高階関数
第14回 行列と回転行列
第15回 複素数とガウス平面．回転の3つの表し方が一致する
