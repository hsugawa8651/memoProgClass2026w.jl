第14回：行列と回転行列

今回は，数を縦横に並べた 行列 を学ぶ． キーワードは 「* は行列積，.* は要素ごとの積」． そして，第5回で手書きした回転の式が 回転行列 R(θ) という1つの行列にまとまり， R(θ) * v を掛けるだけで点や図形を回せることを確かめる．

ノート回転は3度現れる

同じ「回転」が，この教材では 3つの姿 で現れる．

  • 第5回：座標ごとの式で回す（ブロードキャスト）
  • 第14回：回転行列 R(θ) の掛け算1つにまとめる　← いまここ
  • 第15回：複素数 z * cis(θ) の掛け算1つで書く

第15回で，3つが同じ回転であることを1つの点で確かめる． 同じ考えが道具を変えて現れるところが，この教材の見どころである．

行列：数を縦横に並べる

[ ] の中で，スペースで横（列）を区切り，; で縦（行）を区切る と 行列 ができる．

A = [1 2; 3 4]      # 2x2 matrix: row 1 is 1 2, row 2 is 3 4
2×2 Matrix{Int64}:
 1  2
 3  4

行列の 寸法（行数・列数）は size で調べられる．

size(A)             # (rows, cols) -> (2, 2)
(2, 2)

行列の要素は，A[行, 列] の2つの添字 で取り出す（ベクトルの添字が2次元になっただけ）．

重要予測しよう（L1）

A[1, 2] は何番目の要素か？（1行2列）　実行前に予想しよう．

A[1, 2]             # which element is this?
2

行列とベクトルの積

行列にベクトルを掛けると，新しいベクトル ができる． *（ドットなし）は 行列積 を表す．

A * v の i 番目の成分は，A の i 行目と v の内積（対応する成分を掛けて足す）である． たとえば A = [1 2; 3 4]，v = [1, 0] なら

\[ A v = \begin{bmatrix} 1 & 2 \\ 3 & 4 \end{bmatrix} \begin{bmatrix} 1 \\ 0 \end{bmatrix} = \begin{bmatrix} 1\cdot1 + 2\cdot0 \\ 3\cdot1 + 4\cdot0 \end{bmatrix} = \begin{bmatrix} 1 \\ 3 \end{bmatrix}. \]

重要予測しよう（L1）

A * [1, 0] を 手で計算 してから，下のセルで確かめよう．

v = [1, 0]
A * v               # check against your hand calculation
2-element Vector{Int64}:
 1
 3
警告落とし穴：次元が合わないとエラー

行列とベクトルの積は，行列の列数とベクトルの長さが一致 していなければならない． 2×2 の A に長さ 3 のベクトルを掛けると，掛け合わせる相手がなく エラー になる．

@errmsg A * [1, 2, 3]       # cols 2 != length 3 -> DimensionMismatch
DimensionMismatch: matrix A has dimensions (2,2), vector B has length 3

行列積の順序を変えると

行列どうしも * で掛けられる． ただし，ふつうの数のかけ算と同じに考えてよいかは，確かめてみないと分からない．

B = [0 1; 1 0]      # swaps the columns of A when multiplied on the right
A * B
2×2 Matrix{Int64}:
 2  1
 4  3
重要予測しよう（L1）

B * A は A * B と同じになるだろうか？　実行前に予想しよう．

B * A               # same as A * B?
2×2 Matrix{Int64}:
 3  4
 1  2
警告落とし穴：A*B と B*A を混同しない

数のかけ算では 3 * 5 = 5 * 3 だが，行列では A * B と B * A は一般に異なる． 「順序を入れ替えてよい」と思い込むと結果がずれる．順序が結果を決める．

* と .*

第2回のブロードキャストと同じく，. を付けた .* は 要素ごとの積（同じ位置どうしを掛ける）になる．

重要予測しよう（L1）

A .* B は，A * B と同じか違うか？　それぞれ何になるか予想しよう．

A .* B              # multiply matching positions (elementwise)
2×2 Matrix{Int64}:
 0  2
 3  0
警告落とし穴：* と .* の取り違え
  • A * B … 行列積（行と列の内積を並べる）．
  • A .* B … 要素積（同じ位置どうしを掛けるだけ）．

「行列をかけたつもりが要素積だった」は典型的な誤り． 回転や座標変換で使うのは *（行列積） である．

回転行列：第5回の回転式が1つの行列に

第5回では，点 \((x, y)\) を角 \(\theta\) だけ回した先 \((x', y')\) を，手書きで

\[ \begin{aligned} x' &= x\cos\theta - y\sin\theta, \\ y' &= x\sin\theta + y\cos\theta \end{aligned} \]

と計算した．この2本の式は，次の 回転行列 \(R(\theta)\) を使った 1つの積 にまとめられる．

\[ R(\theta) = \begin{bmatrix} \cos\theta & -\sin\theta \\ \sin\theta & \cos\theta \end{bmatrix}, \qquad \begin{bmatrix} x' \\ y' \end{bmatrix} = R(\theta) \begin{bmatrix} x \\ y \end{bmatrix}. \]

Julia では，θ を受け取って行列を返す 関数 として書ける．

R(θ) = [cos(θ) -sin(θ); sin(θ) cos(θ)]
R (generic function with 1 method)

点 \((1, 0)\) を \(45° = \pi/4\) だけ回してみる．

R(π/4) * [1.0, 0.0]     # rotate point (1,0) by 45 deg -> about (0.707, 0.707)
2-element Vector{Float64}:
 0.7071067811865476
 0.7071067811865475
ノート補足：角度はラジアン

角度は ラジアン で与える（180° が π，90° が π/2）．第5回と同じである．

きりのよい角で確かめると，回転の意味がはっきりする．

R(π/2) * [1.0, 0.0]     # rotate 90 deg: (1,0) -> nearly (0, 1)
2-element Vector{Float64}:
 6.123233995736766e-17
 1.0
R(π) * [1.0, 0.0]       # rotate 180 deg: where does (1,0) land?
2-element Vector{Float64}:
 -1.0
  0.0
ノート補足：6.12e-17 のような値が見えても

cos(π/2) は厳密な 0 ではなく ごく小さな誤差 を含む（浮動小数点数の宿命）． 6.12e-17 のような値は 実質ゼロ と読めばよい． いっぽう R(π) の計算に誤差が出ないのは，Julia が π を特別に扱い， sin(π) を厳密に 0.0 と返すからである．

内積：長さと角度を測る道具

2つのベクトルの 内積 は，対応する成分どうしを掛けて足したもの である．

\[ v \cdot w = v_1 w_1 + v_2 w_2 \]

第2回の要素ごとの積 .* と，第12回の sum で書ける．

v = [3.0, 4.0]
w = [1.0, 0.0]
sum(v .* w)                 # dot product of v and w
3.0

内積が役に立つのは，長さと角度が内積で測れるからである．

  • 自分自身との内積は 長さの2乗：\(v \cdot v = |v|^2\)
  • 2つのベクトルが 直交（90度）なら，内積は 0 になる
[sum(v .* v), sqrt(sum(v .* v))]      # |v|^2 and |v|
2-element Vector{Float64}:
 25.0
  5.0
sum([1.0, 0.0] .* [0.0, 1.0])         # two perpendicular vectors -> 0
0.0

回転で長さはどうなるか（L3：不変量）

第5回で「回転しても点と原点の距離は変わらない」ことを確かめた（L2）． 回転行列でも同じはずである．回転後のベクトル \(w = R(\theta)\,v\) の 長さ \(\sqrt{x'^2 + y'^2}\) を計算し， 元の長さ 1 と一致するかを 検証 しよう．

重要予測しよう（L1）

点 \((1, 0)\)（長さ 1）を \(45°\) 回した先の長さは，いくつになるはずか？

w = R(π/4) * [1.0, 0.0]
sqrt(w[1]^2 + w[2]^2)   # how long is w?
1.0

長さが 1 のまま変わらない．これが 回転の不変量（長さ保存）であり， 回転行列が 直交行列 であることの現れである． 符号を1つでも間違える（たとえば sin の符号を逆にする）と，この長さ不変が破れたり，逆回転になったりする．

図形を丸ごと回す（第5回ブロードキャストの行列版）

各頂点 \((x, y)\) を 列 に並べた 2×N の行列 P を作れば，R(θ) * P だけで 全頂点を一度に回転 できる．第2回で .+ を覚え，第5回で図形を平行移動して座標ごとの式で回転したのと 同じ回転を，行列という別の表現で 行っているのである．

P = [0 2 2 0 0;        # each column is a vertex (x, y): row of x coords
     0 0 1 1 0]        # row of y coords (the square from lesson 2)
2×5 Matrix{Int64}:
 0  2  2  0  0
 0  0  1  1  0
Q = R(π/6) * P         # rotate all vertices by 30 deg (one matrix product)
2×5 Matrix{Float64}:
 0.0  1.73205  1.23205  -0.5       0.0
 0.0  1.0      1.86603   0.866025  0.0

回す前と後を重ねて描く．行列の 1行目が x 座標，2行目が y 座標 なので，P[1, :]・P[2, :] で取り出す．

ノート補足：aspect_ratio（第5回で扱った歪み対策）

正方形を正しく正方形に見せるため，第5回と同じく縦横の比を1にする（aspect_ratio=:equal，数値で =1 と書いても同じ）．

using Plots
plot(P[1, :], P[2, :], label="original", aspect_ratio=:equal)
plot!(Q[1, :], Q[2, :], label="rotated 30 deg")
ノート補足：第15回への伏線

回転には 3つの表現 がある．第5回の 手書きの式，今回の 行列 R(θ)， そして第15回で学ぶ 複素数 z·e^{iθ}．同じ回転を別の言葉で書いているだけで， 複素数の表現が最もコンパクトになる．

今回のまとめ

  • 行列 は [1 2; 3 4]（スペースで列，; で行）．寸法は size，要素は A[行, 列] の2添字．
  • 行列とベクトルの積 A * v は，各行とベクトルの内積を並べたもの．列数と長さが合わないとエラー．
  • 行列積 * は 非可換：A * B ≠ B * A．順序が結果を決める．
  • *（行列積）と .*（要素積）は別物．回転で使うのは *．
  • 回転行列 \(R(\theta) = \begin{bmatrix}\cos\theta & -\sin\theta \\ \sin\theta & \cos\theta\end{bmatrix}\)．第5回の回転式が1つの行列に．
  • 回転は 長さを保存 する（不変量・直交行列）．第5回の L2 検証と同じ見方である．
  • R(θ) * P で 図形を丸ごと回せる（第5回ブロードキャストの行列版）．

この回で使った関数

  • cos（日本語訳）
  • sin（日本語訳）

ヒント練習
  1. A = [1 2; 3 4] と v = [2, 1] について，A * v を 手で計算 してから確かめよ．
  2. A .* A と A * A をそれぞれ予測してから実行し，違いを説明せよ．
  3. R(π/3) * [1.0, 0.0] を実行し，長さ \(\sqrt{x^2 + y^2}\) が 1 になることを確かめよ．
  4. 自分で三角形などの頂点を 2×N 行列 P で作り，R(θ) で好きな角に回して plot で重ねて描け．
