第5回：平面図形の変形

今回は，図形を 座標ベクトル (xs, ys) で表し，それを 変形 する． まず簡単な変形（平行移動 と 伸縮）から始め，回転 へ進む．回転には sin・cos が要る． 図形を正しい形で見せるための アスペクト比 = 1 も，ここで導入する．

ノート回転は3度現れる

同じ「回転」が，この教材では 3つの姿 で現れる．

  • 第5回：座標ごとの式で回す（ブロードキャスト）　← いまここ
  • 第14回：回転行列 R(θ) の掛け算1つにまとめる
  • 第15回：複素数 z * cis(θ) の掛け算1つで書く

第15回で，3つが同じ回転であることを1つの点で確かめる． 同じ考えが道具を変えて現れるところが，この教材の見どころである．

using Plots
ノート

このノートブックの先頭の準備セルで using Plots と日本語フォントの設定を済ませてある． 自分で新しく書き始めるときは，最初に一度 using Plots を実行する．

図形を座標で表す（とアスペクト比 = 1）

図形は，頂点の x 座標 と y 座標 を2つのベクトルで表す（最後に始点を繰り返して閉じる）．

xs = [0, 1, 1, 0, 0]   # x coordinates of square vertices
ys = [0, 0, 1, 1, 0]   # y coordinates
plot(xs, ys)
警告正方形なのに長方形に見える

これは 正方形 の座標なのに，画面では縦横に歪んで見える． データの座標 と 画面上の座標 の比が違うからである．

plot に aspect_ratio=:equal を渡すと，横1目盛りと縦1目盛りを同じ長さに揃え， データ座標と画面座標の比が 1対1 になる．

重要予測しよう（L1）

aspect_ratio=:equal を付けると，正方形はどう見えるだろうか．

plot(xs, ys, aspect_ratio=:equal)   # make x and y scales 1:1
ヒント

正方形が 真四角 に見えた． 円・正方形など「縦横の比が意味を持つ図形」を描くときは aspect_ratio=:equal． これが今回のかなめのひとつ．忘れると図形が潰れる．

平行移動：全点に同じだけ足す

図形を 横へ動かす には，全部の x 座標に同じ数を足す． ベクトルに数を足すのは「そのままでは定義されていない」ので， ブロードキャスト .+（第2回の峻別）を使う．

plot(xs .+ 2, ys, aspect_ratio=:equal)    # translate right by 2

縦へ動かすなら ys に足す．

plot(xs, ys .+ 0.5, aspect_ratio=:equal)  # translate up by 0.5

伸縮：スカラー倍

図形を 拡大・縮小 するには，座標を 何倍か する． スカラー倍 2 * xs は 定義済み なので，ドットは要らない（第2回の峻別）．

plot(2 * xs, ys, aspect_ratio=:equal)        # scale x by 2 (wider)
plot(2 * xs, 2 * ys, aspect_ratio=:equal)    # scale both by 2 (similar enlargement)

回転には sin・cos が要る

平行移動・伸縮は，足し算・かけ算だけでできた．回転 はそうはいかず， 角度の関数 sin・cos が要る．

点 (x, y) を原点まわりに角 θ だけ回した先 (x', y') は，

\[ x' = x\cos\theta - y\sin\theta, \qquad y' = x\sin\theta + y\cos\theta \]

で与えられる（三角関数の加法定理から導ける；行列・複素数による見方は 第14・15回）．

警告度とラジアン

Julia の sin と cos は ラジアン を受け取る（半回転 = π ラジアン = 180度）． 円周率は π として組み込まれており，そのまま使える（pi と書いてもよい）． 「30度」のつもりで sin(30) と書くと 30 ラジアン（約1719度）と解釈され，まったく違う値になる． 度で渡したいときは sind・cosd（末尾 d = degree）を使う．

sin(30)      # interpreted as 30 radians (~ -0.988); wrong if you meant 30 degrees
-0.9880316240928618
sind(30)     # sin of 30 degrees
0.5

まず1点 (1, 0) を θ = π/4（45度）回す．cos(θ)・sin(θ) はスカラーなので， 式はそのまま書ける（ドット不要）．

重要予測しよう（L1）

(1, 0) を反時計まわりに45度回すと，どのあたりに来るか？　x 座標と y 座標の大小はどうなるか．

θ = π/4
x0 = 1.0
y0 = 0.0
x1 = cos(θ)*x0 - sin(θ)*y0
y1 = sin(θ)*x0 + cos(θ)*y0
[x1, y1]                     # compare with your prediction
2-element Vector{Float64}:
 0.7071067811865476
 0.7071067811865475

回転の大事な性質は 長さ（原点からの距離）を変えない こと．

長さは \(\sqrt{x^2+y^2}\) で求まる．平方根は sqrt で計算する．

[sqrt(x0^2 + y0^2), sqrt(x1^2 + y1^2)]   # length before and after the rotation
2-element Vector{Float64}:
 1.0
 1.0

図形を丸ごと回す

回転式の cos(θ) と sin(θ) は スカラー，xs と ys は ベクトルである． cos(θ)*xs も sin(θ)*ys も，第2回で学んだ スカラー倍 である． そして 要素数が同じベクトルどうしの引き算も定義されている． だから回転式は ドット無しのまま，図形を丸ごと回せる．

θ = π/6
xr = cos(θ)*xs - sin(θ)*ys    # rotate all vertices at once (no dot needed)
yr = sin(θ)*xs + cos(θ)*ys
plot(xs, ys, aspect_ratio=:equal)   # original square
plot!(xr, yr)                       # overlay the rotated one
重要予測しよう（L1）

回転した結果を，元と同じ名前に書き戻すとどうなるか． 点 \((1,0)\) と \((0,1)\) を \(\theta=\pi/6\) 回したとき，長さは 1 のままだろうか．

ax = [1.0, 0.0]               # two points: (1,0) and (0,1)
ay = [0.0, 1.0]
ax = cos(θ)*ax - sin(θ)*ay    # write the result back into ax
ay = sin(θ)*ax + cos(θ)*ay    # ... and use ax again here
[sqrt(ax[1]^2 + ay[1]^2), sqrt(ax[2]^2 + ay[2]^2)]   # lengths: should both be 1
2-element Vector{Float64}:
 0.9682458365518543
 0.7934023557488223
警告落とし穴：結果を同じ名前に書き戻す

1行目で ax は 回転後の値 に変わる． 2行目はその ax を使ってしまうので，計算しているのは もう回転ではない． エラーは出ず，図もそれらしく描けるので，気づきにくい．

見抜く手がかりは 回転は長さを変えない ことである． 長さが 1 から崩れていれば，どこかが壊れている．

直し方は2つある．ひとつは 結果を別の名前に受けることである（本文の xr，yr）． もうひとつが次の 同時代入 である．

同時代入：右辺を先に全部計算する

= の左右に 同じ個数 を並べると，まとめて代入できる．

x, y = 1, 2        # x gets 1, y gets 2
[x, y]
2-element Vector{Int64}:
 1
 2

右辺には式を書いてもよい．大事なのは，右辺を先に全部計算してから 左へ配ることである．

a = 10
x, y = a + 1, a * 2
[x, y]
2-element Vector{Int64}:
 11
 20

この規則のおかげで，値の交換が1行で書ける． 右辺の y, x は 交換する前の値 が読み取られるので，一時変数が要らない．

重要予測しよう（L1）

x, y = y, x と，x = y に続けて y = x と書くのとでは，結果が違う．どう違うか．

x = 1
y = 2
x, y = y, x        # the right-hand side is read first
[x, y]
2-element Vector{Int64}:
 2
 1

x = y に続けて y = x と書くと，1行目で x が 2 になり，2行目はその x を使うので 両方が 2 になる．上の落とし穴と同じ型の誤りである．

回転も，同時代入なら1行で書ける（xs，ys を壊さずに済む）．

xr, yr = cos(θ)*xs - sin(θ)*ys, sin(θ)*xs + cos(θ)*ys

コードは上から順に実行され，順序が結果を決める（第1回）． 同時代入は，その中で 右辺が先 という規則を与える．

発展：ベクトルどうしの加減算

ノート

ここから先は 発展（必修ではない）．「どこにドットが要るのか」を整理したい人向けである． 読み飛ばして，次の 「θ を振って回転の連続を見る」 へ進んでよい．

要素数が同じベクトルどうしなら，足し算も引き算も そのまま書ける．

[10, 20, 30] - [1, 2, 3]      # vector - vector of the same length is defined
3-element Vector{Int64}:
  9
 18
 27

第2回で xs + 1 がエラーになったのは，ベクトルとスカラーの 形が違う からである． 形が同じなら定義済み，形が違うならドットを付けて要素ごとに，と整理できる．

ノート

plot!（末尾 !）は 今ある図に重ね描き する命令である． plot が新しい図を作るのに対し，plot! は直前の図へ追加する．

L2検証：回転は長さを保つので，各頂点の x² + y² は回転の前後で一致するはず （ここは .^ ＝要素ごとのべき乗 なのでドットが要る）．

xs.^2 .+ ys.^2     # (length)^2 of each vertex before rotation
5-element Vector{Int64}:
 0
 1
 2
 1
 0
xr.^2 .+ yr.^2     # (length)^2 after rotation; compare with the line above
5-element Vector{Float64}:
 0.0
 1.0
 2.0
 1.0
 0.0

θ を振って回転の連続を見る

回転角 θ を for で 0 から π/2 まで少しずつ振り，そのたびに plot! で重ねれば， 図形が だんだん回っていく 様子が見える（第3回の「パラメータ作図」と合流する）．

plot(aspect_ratio=:equal)          # start with an empty figure (ratio = 1)
for θ in 0:π/6:π/2                  # sweep θ over 0, π/6, π/3, π/2
    xr = cos(θ)*xs - sin(θ)*ys
    yr = sin(θ)*xs + cos(θ)*ys
    plot!(xr, yr)                  # overlay the square for each θ
end
plot!()                            # finalize and display the figure

円を描く（パラメトリック）

sin・cos を使うと，円 も描ける．y = f(x) のグラフ（第2回）は同じ x に y ひとつの形しか描けないが， 媒介変数 t（角度） を 0 から 2π まで振り，x = cos(t)，y = sin(t) とすると円になる （これを パラメトリック曲線 という）．

t はベクトルなので，cos(t) とは書けない（cos は数ひとつを受け取る関数である）． 関数名に . を付けて cos.(t) と書くと，t の各要素に cos を当てた結果がベクトルで返る． 演算子に付けるドット（第2回の .+）と同じ考え方で，要素ごとに という指示である．

t = 0:0.01:2π
plot(cos.(t), sin.(t), aspect_ratio=:equal)   # unit circle (aspect=1 makes it a true circle)
ヒント発展：楕円・渦

x を a 倍・y を b 倍すれば 楕円（横半径 a，縦半径 b）， 半径を r = t と増やしながら r .* cos.(t)・r .* sin.(t) とすれば アルキメデスの渦 になる．

発展：関数グラフにもアスペクト比 = 1

ノート

ここは 発展．関数グラフ（第2回）でも， x と y を同じ尺度で見たい ときは aspect_ratio=:equal を付ける．

\(y = x^n\) と，その 逆関数 \(y = x^{1/n}\)（\(n\) 乗根）は，直線 \(y = x\) を鏡とした鏡像 である （第4回で見たべき乗則 \(y = x^n\) の，指数が \(1/n\) の場合にあたる）． これを正しく観察するには，y = x を本当に45度に見せる アスペクト比 = 1 が要る．

x = 0:0.01:1
plot(x, x.^2,   label="y = x^2",  aspect_ratio=:equal)   # power
plot!(x, x.^0.5, label="y = x^(1/2)")                    # inverse function (1/2 power = sqrt(x))
plot!(x, x,     label="y = x", linestyle=:dash)          # mirror axis

アスペクト比 = 1 だから，y = x² と y = √x が y = x を挟んで きれいに対称（鏡像） に見える． 外すと y = x が45度に見えず，鏡像であることが分かりにくい．

今回のまとめ

  • 図形は 座標ベクトル (xs, ys) で表す．aspect_ratio=:equal で縦横を1:1にすると，図形が正しい形で見える（忘れると潰れる）．
  • 平行移動は全点に足す → ブロードキャスト xs .+ c（足し算は未定義なのでドット要）．
  • 伸縮はスカラー倍 → 2 * xs（定義済みなのでドット不要）．
  • 回転 には sin と cos が要る：\(x' = x\cos\theta - y\sin\theta\)，\(y' = x\sin\theta + y\cos\theta\)．スカラー倍とベクトルの引き算なので ドット無しで図形を丸ごと回せる．
  • 回転は長さを保つ：x² + y² は回転の前後で不変（第14・15回への伏線）．
  • Julia の sin・cos は ラジアン．度は sind・cosd．sin(30) ≠ 30度の sin．
  • sin・cos で 円（パラメトリック）も描ける．（発展）関数グラフでも，逆関数の鏡像を見るには aspect_ratio=:equal．
