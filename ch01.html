第1回：変数・代入・再代入

今回の目標は，命令型プログラミングの心臓である 「変数」「代入」「四則演算」「逐次実行」，とりわけ 変数への再代入 を身につけることである． あわせて，毎回の習慣にしたい 「実行する前に結果を予測する」 ことを始める．

ノートノートブックの使い方（最初に）
  • コードセル：Julia の命令を書き，SHIFT + ENTER で実行する．
  • Markdown セル：文章を書く．コードとして実行されない部分である． SHIFT + ENTER で清書（レンダリング）される．
    • 段落を分けるには，間に空行を1つ入れる（ENTER を2回）． 改行1回では段落は分かれず，文が詰めて表示される．
    • 見出しは #，箇条書きは -（前に空行）．

変数と代入

x = 2 と書くと，名前 x を値 2 に結びつける． これを 代入 という．

ヒント札（名札）モデル

Julia の変数は「値を入れる箱」ではなく，値に貼る名札だと考えるとよい． x = 2 は「箱に 2 を入れる」のではなく，「名前 x を値 2 に結びつける」．

重要実行する前に予測しよう（L1）

次のセルで z はいくつになるか，実行する前に予想してみよう．

x = 2
y = 3
z = x + y
5
警告数学の = とプログラミングの = は別物
  • 数学の = は「左右が等しい」という関係を表す（1 + 1 = 2）． 左右を入れ替えても成り立つ（2 = 1 + 1 も正しい）．
  • プログラミングの = は 代入，すなわち「右辺の値を，左辺の名前に結びつける」． 向きがある（右 → 左）ので，左右は入れ替えられない（2 = x は意味をなさず，エラーになる）．

だから x = 2 は「x と 2 が等しい」という主張ではなく， 「名前 x を値 2 に結びつける」操作である．左右が等しいかを調べたいときは， 比較演算子 ==（後で出てくる）を使う．

ノート変数名のつけ方

変数名は 英字で始め，英数字と _（アンダースコア）を組み合わせて作る （x，x1，my_value など）．数字で始まる名前は付けられない． 1x と書くと，これは名前ではなく 1 * x の意味になる（第8回の 2i も同じ書き方である）． 大文字・小文字は区別される（x と X は別の名前）． Julia では π（\pi と打って TAB）のような ギリシャ文字 も変数名に使える （第5回以降で角度に θ などを使う）．

ノートコメント #

コードの中に # を書くと，その行の # から右側はコメント（人間向けのメモ）になり， 実行されない．このあとのコード例にも # … の注釈を付けてある． 自分のコードにも「何をしているか」をメモしておくと，あとで読み返しやすい．

1 + 2     # the text after '#' is a comment (not executed)
3

四則演算と演算子の優先順位

Julia は電卓のように計算できる．スカラー（ひとつの数）どうしの 四則演算 は， +（加算），-（減算），*（乗算），/（除算）で行う．

7 + 2
9
7 - 2
5
7 * 2
14
重要予測しよう（L1）

7 / 2 はいくつになるか？

7 / 2       # integer or not?
3.5
ノート

整数どうしでも / の結果は 小数（浮動小数点数）になる． 整数の割り算（商と余り）は 第9回 でくわしく扱う．

演算子には 優先順位 がある．数学と同じく，*・/ は +・- より 先に 計算され，べき乗 ^ はさらに先に計算される（^ ＞ *,/ ＞ +,-）．

重要予測しよう（L1）

2 + 3 * 4 はいくつか？　* と + のどちらが先に計算されるだろうか．

2 + 3 * 4      # which operator goes first?
14
2 * 3 ^ 2      # which is applied first, ^ or *?
18

括弧 ( ) を使えば，計算の順序を変えられる．

(2 + 3) * 4    # parentheses change the order
20

優先順位は，実際の計算で 答えを左右する． たとえば二つの数の 平均 は (10 + 20) / 2（＝ 15）である． 括弧を忘れて 10 + 20 / 2 と書くと，/ が + より先に計算される． つまり 10 + (20 / 2)（＝ 20）となり，まったく別の値 になってしまう．

(10 + 20) / 2    # the average of 10 and 20
15.0
10 + 20 / 2      # the same digits without parentheses
20.0

変数への再代入

すでに使った名前に，もう一度 = で別の値を結びつけ直すことができる． これを 再代入 という．

重要正しい考え方

x = x + 1 は，

  1. 右辺を「今の x」を使って計算し（x が 2 なら 2 + 1 = 3），
  2. その結果に 名前 x を結びつけ直す（再束縛・名札の貼り替え）．

右が先，左は後．古い値は書き換わらず，x が新しい値を指すだけである．

重要予測しよう（L1）

各行の実行後に x がどう変わるか，下の表を実行前に自分で埋めてみよう．

行 実行後の x（予測）
x = 2
x = x + 1
x = x + 1
x = x * 10 
x = 2
x = x + 1     # right side first, then rebind the name x
x = x + 1
x = x * 10
40

「頭の中でコードを実行する（トレース）」ことが，検証の最初の一歩である． 表と実行結果は一致しただろうか．

警告よくある誤解：x = x + 1 は矛盾ではない

数学の =（左右が等しいという主張）として x = x + 1 を読むと， 両辺から x を引けば「0 = 1」となり，どんな x でも成り立たない 偽の命題になる． しかしプログラムの = は 代入 であって等式の主張ではないので， x はきちんと更新される（上で確かめた）．

比較演算子 == は「左右が 等しいか」を調べる． その結果は，数ではなく true（真） か false（偽） という 論理値（Bool 型）になる．

2 == 2        # are the two sides equal?
true
x = 3
x == x + 1    # is x equal to x plus one?
false
ノート

true / false と，比較演算子（<，>，== など）や論理型については， 第6回（条件分岐）でくわしく扱う．ここでは「= は代入，== は比較」の区別と， 比較の結果が true/false になることだけ押さえればよい．

逐次実行と順序

コードは上から順に実行され，変数に結びついた値が変わっていく． 順序が結果を決める．

重要予測しよう（L1）

次のセルで，最後に表示される b はいくつか？ （a を後から変えても，すでに計算済みの b は変わるだろうか？）

a = 1
b = a + 1
a = 100       # does this change b?
b
2

再代入が生むパターン（次回への伏線）

再代入は，このあとのほぼ全アルゴリズムの種になる． たとえば，繰り返しの中で

s = s + x     # accumulation (accumulator): see Lesson 3

のように値をためていく．今は「同じ仕組みが何度も出てくる」ことだけ覚えておこう．

ノート札モデルの伏線

b = a のように，同じ値を指す2枚の名札ができることがある． スカラー（数）では差が見えないが，配列（第8回）では効いてくる．

今回のまとめ

  • 変数は 名札（値に結びつける）．= は 代入であって等式ではない．
  • 四則演算は + - * /．優先順位は ^ ＞ *,/ ＞ +,-，括弧 ( ) で順序を変えられる．
  • 再代入 x = x + 1 は「右辺を今の値で計算 → 名前を貼り替える」．
  • コードは 上から順に実行され，順序が結果を決める．
  • 実行する前に 予測する（L1検証）習慣をつける．

この回で使った関数

  • plot … Plots.jl のドキュメント（日本語訳なし）
ヒント練習

  1. 次を実行する前に，最後の p を予測せよ．

    p = 5
p = p * p
p = p - 1

  2. 次を実行したあと，r はいくつか予測してから確かめよ．

    q = 10
r = q
q = q + 1

  3. r = 5 のとき円の面積 area = 3.14 * r^2 を計算せよ．次に r = 10 に再代入して 同じ式を実行し，area がどう変わるか予測してから確かめよ（再代入と四則演算の練習）．

やってみよう：図形を描く（次回の予告）

次回（第2回）でくわしく学ぶ ベクトル […] と plot を使うと，図形 も描ける． 下のコードを コピーして実行し，どんな形になるか， まず 予測してから 確かめよう．書き方は 第2回 で学ぶ．

using Plots
xs = [0, 2, 2, 0, 0]   # x coordinates of the corners (last repeats the first)
ys = [0, 0, 2, 2, 0]   # y coordinates
plot(xs, ys)

xs，ys の 同じ位置どうし を (0,0) → (2,0) → (2,2) → (0,2) → (0,0) と 順に線でつなぐと，四角形 になる．数につけた名前（変数）が，こんな絵にもつながっていく． 第2回 で，この ベクトル と プロット を本格的に学ぼう．
