第4回：対数グラフで直線化・数式モード

今回の背骨は 「どの対数軸で直線になるかで，法則を見抜く」 である． 線形軸では急上昇の曲線にしか見えない関係も，対数軸に取り替えると直線になることがある． べき乗則 \(y=x^{n}\) は両対数で直線，指数則 \(y=a^{x}\) は片対数で直線である． あわせて，レポート作法の2回目として 数式モード（$…$・$$…$$・上付き・下付き・分数）を導入する．

線形軸では見分けにくい

まずプロットの準備として，Plots パッケージ を読み込む （自分で書き始めるときは，最初に一度 using Plots を実行する）．

using Plots

べき乗則 \(y=x^{3}\) と 指数則 \(y=2^{x}\) を，ふつうの（線形の）軸で描いてみる． 第2回・第3回と同じく，ブロードキャスト式（.）で y を一気に計算する． べき乗は ^ で，ベクトルの要素ごとのべき乗には . を付けて .^ と書く（第2回の峻別）．

t = 0.1:0.1:10
y = t .^ 3          # power law y = x^3 (cube every element)
plot(t, y)
x = 0:0.5:10
z = 2 .^ x          # exponential law y = 2^x (2 raised to each element)
plot(x, z)
重要予測しよう（L1）

上の2枚のグラフは，どちらも右へ行くほど 急上昇 する曲線である． 線形軸のこの見た目だけで，「これはべき乗だ／これは指数だ」と 見分けられるだろうか？

両対数で直線になる＝べき乗則

plot に xscale=:log10, yscale=:log10 を渡すと，両対数（log-log）グラフになる． 名前=値 の形は，プロットの 指定 を渡す書き方である． :log10 のように : で始まる語は，設定の名前 を表す（文字列ではない）． 横軸・縦軸の 両方を対数目盛にするので，べき乗則 \(y=x^{n}\) が 直線になる．

plot(t, y, xscale=:log10, yscale=:log10)   # what shape does the curve take here?
ノート対数軸では，点も対数の等間隔で取る

0.1:0.1:10 のような 等差 の刻みでは，対数軸の左側に点が集まり，右側がまばらになる． 自分で点を選べるなら，対数軸で見るデータは 10のべき乗で等間隔 に取ると，図全体に点が散る． range(a, b, length=n) は a から b までを n 個に等分した列を作るので， その指数で10のべき乗にすればよい．

10 .^ range(-1, 1, length=5)      # 5 points spread evenly on a log scale
5-element Vector{Float64}:
  0.1
  0.31622776601683794
  1.0
  3.1622776601683795
 10.0

range(a, b, length=n) の length=n は，個数を指定する 書き方である． 逆に，できあがった列の 個数を数える には，関数 length を使う． length([10, 20, 30]) は 3 である．

重要予測しよう（L1→L2）

range(-1, 1, length=5) の個数を length で数えると，いくつになるか． 等差の刻み 0.1:0.1:10 ではどうか．実行する前に予想しよう．

length(range(-1, 1, length=5))    # count the points: compare with length=5
5
length(0.1:0.1:10)                # count the arithmetic sequence
100
ノート個数は for 文でも数えられるか

第3回の足しこみ s = s + x と同じ形で，for 文を使って要素数を数えられないか考えよう． 数えた結果が length と一致すれば，どちらも信頼できる．解き方は一つではない． 平均は「合計 ÷ 個数」なので，合計を for 文で足しこみ，個数を length で求めれば書ける．

警告落とし穴：線形軸で法則を主張してはいけない

線形軸では，べき乗 \(x^{3}\) も指数 \(2^{x}\) も「急に立ち上がる曲線」にしか見えず， 見た目で区別できない． 「曲線が急だから指数だ」と断定するのは誤りである． 法則を見抜くには，適切な対数軸で直線になるかを確かめる必要がある．

重要予測しよう（L1→L2）

この直線の 傾きはいくつだろうか？ \(x\) が \(1\to 10\)（10倍）と動くとき，\(y=x^{3}\) は \(1\to 1000\)（1000倍）になる． 対数の世界での増分の比 \(\dfrac{\Delta \log y}{\Delta \log x}\) を予想してみよう．

両対数で直線になり，その 傾きが指数 \(n\) そのものになる．これがべき乗則の指紋である：

\[ y = x^{n}, \qquad \log y = n \log x . \]

\(y=x^{3}\) なら \(\log y = 3\log x\) なので，傾きは \(3\) になる． 実際，\(x:1\to 10\) で \(\log x:0\to 1\)（増分 \(1\)），\(y:1\to 1000\) で \(\log y:0\to 3\)（増分 \(3\)）， よって \(\dfrac{\Delta\log y}{\Delta\log x}=\dfrac{3}{1}=3\)．

ノート添字 \(i\) で書く対数の傾き

二つの点 \((x_1,y_1)\)，\((x_2,y_2)\) から傾きを読むなら， \[ n = \frac{\log y_2 - \log y_1}{\log x_2 - \log x_1} . \] 下付き（subscript）$x_1$，$x_2$ の書き方は，後半の数式モードで説明する．

片対数で直線になる＝指数則

今度は yscale=:log10 だけを渡す（横軸はそのまま）．これが 片対数（semilog-y）である． 縦軸だけを対数目盛にすると，指数則 \(y=a^{x}\) が 直線になる．

plot(x, z, yscale=:log10)   # semilog-y: what shape does the exponential take?

指数則は，対数を取ると \(x\) の1次式になる：

\[ y = a^{x}, \qquad \log y = (\log a)\, x . \]

\(y=2^{x}\) なら \(\log_{10} y = (\log_{10} 2)\,x\) で，\(x\) に対して直線になり， 傾きは \(\log_{10} 2 \approx 0.301\) である（\(x:0\to 10\) で \(y:1\to 1024\)）．

重要予測しよう（L2）：軸を取り違えると

指数則 \(y=2^{x}\) を，まちがえて 両対数で描くとどうなるだろうか？ 直線になるだろうか，それとも曲がるだろうか？

plot(x, z, xscale=:log10, yscale=:log10)   # straight or curved?

指数則は 片対数で直線，両対数では曲がる． 逆にべき乗則は 両対数で直線，片対数では曲がる． どの軸で直線になるかが，そのまま法則の正体を教えてくれる．

ヒント法則の同定：早見表
直線になる軸 法則 式 傾きの意味
両対数（log-log） べき乗則 \(y=x^{n}\) 指数 \(n\)
片対数（semilog-y） 指数則 \(y=a^{x}\) \(\log a\)

「両対数で直線なら べき乗」「片対数で直線なら 指数」．

落とし穴：対数のとれない値

対数は 正の数にしか定義されない．データに \(0\) や負の数が混ざると， 対数軸では値が壊れてしまう．

log(0) は \(-\infty\)（-Inf）になる：

log(0.0)
-Inf

負の数の対数は エラー（DomainError）になる：

@errmsg log(-1.0)   # log of a negative number
DomainError with -1.0:
log was called with a negative real argument but will only return a complex result if called with a complex argument. Try log(Complex(x)).
警告落とし穴：0 や負を含むデータを対数軸に乗せない

データに \(0\) が混じると，その点は \(-\infty\) になって図が壊れる（軸が伸びきる・点が消える）． 負の値が混じれば DomainError で描画自体が失敗する． 対数軸を使う前に，データが正であることを確かめる（前処理が要る）のが鉄則である． 今回のべき乗の \(t\) を 0.1 から始めたのは，\(0\) を避けるためであった．

レポート作法（2回目）：数式モード

これまでの回にも，本文には \(y=x^{3}\) のような式が出てきた． ここでは，それを 自分の notebook に書く 方法を学ぶ．

Jupyter の Markdown セルは，$…$ で囲んだ部分を 数式としてレンダリングする． 次の雛形をコピーして中身を書き換えれば，レポートに必要な数式は書ける．

ノートインライン数式とディスプレイ数式
  • インライン：文中に $…$ で埋め込む．例：$y = x^2$ → \(y = x^2\)．
  • ディスプレイ：本文と分けて中央に大きく出す．$$…$$ で囲む（前後は空行）．
べき乗則は両対数で直線になり，傾きが指数を表す．

$$
y = x^{n}, \qquad \log y = n \log x
$$
ノート上付き・下付き・分数
  • 上付き（superscript）：$x^2$ → \(x^2\)．2文字以上は 波括弧で囲む：$x^{10}$ → \(x^{10}\)．
  • 下付き（subscript）：$x_1$ → \(x_1\)．2文字以上は $x_{ij}$ → \(x_{ij}\)．
  • 分数：$\frac{a}{b}$ → \(\dfrac{a}{b}\)．

組み合わせると，今回の傾きの式はこう書ける：

$$
n = \frac{\log y_2 - \log y_1}{\log x_2 - \log x_1}
$$

→ \(\displaystyle n = \frac{\log y_2 - \log y_1}{\log x_2 - \log x_1}\)

重要予測しよう（L1）：Markdown の落とし穴の例

Markdown セルに，$ で囲まずに素で次のように書くとどう表示されるか， レンダリングする前に予想しよう．

  • x^2 と書いたら，上付きになるだろうか．
  • x_1 と書いたら，_ は何として読まれるだろうか．

Markdown セルに書いて，レンダリングして確かめよう．

今回のまとめ

  • 線形軸では，べき乗 \(x^{3}\) も指数 \(2^{x}\) も急上昇の曲線で 見分けられない．
  • 両対数（xscale=:log10, yscale=:log10）で直線 ⇒ べき乗則 \(y=x^{n}\)，傾き＝指数 \(n\)．
  • 片対数（yscale=:log10）で直線 ⇒ 指数則 \(y=a^{x}\)．両対数では曲がる．
  • どの軸で直線になるかが，そのまま法則の同定になる．
  • 対数は 正の数だけ：\(\log 0=-\infty\)，\(\log(\text{負})\) は DomainError．データの前処理が要る．
  • 数式モード：$…$／$$…$$，上付き x^{n}，下付き x_1，分数 \frac{a}{b}．素の x^2・x_1 は崩れるので $…$ で囲む．
  • length(xs) は要素の 個数 を返す．range(…, length=n) の length=n は個数の 指定．
