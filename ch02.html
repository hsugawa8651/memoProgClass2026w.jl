第2回：ベクトルと基本プロット

今回は，複数の数を ひとつの名前でまとめて扱う「ベクトル」 を学ぶ． キーワードは 「全部を変換するならブロードキャスト，一部を選ぶなら添字（スライス）」． そして，座標ベクトルを plot に渡して 関数のグラフ と，点をつないだ 図形 を描く．

ベクトル：複数の数をひとつの名前で

[ ] の中に数を並べると ベクトル（数の並び）ができる． ベクトルは ひとつのエンティティ（ひとかたまり） として扱う．

xs = [10, 20, 30, 40]
4-element Vector{Int64}:
 10
 20
 30
 40

連続した値は 範囲 start:step:stop でまとめて作れる．

0:0.5:3
0.0:0.5:3.0
警告落とし穴：: と四則演算のどちらが先か

範囲の : は，加減乗除（+ - * /）より優先順位が低い． だから 2:2:4*2 は (2:2:4)*2 ではなく，* が先に計算されて 2:2:(4*2) ＝ 2:2:8 （＝ [2, 4, 6, 8]）と解釈される．紛らわしいときは 括弧 で囲む（(2:2:4) のように）．

2:2:4*2      # ':' has low precedence; where does the range end?
2:2:8

スカラー倍とブロードキャスト

ベクトルには，もとから定義された演算がある．スカラー倍（ベクトルを何倍かに伸ばす）は そのまま書ける（ドットは要らない）．

2 * [1, 2, 3]            # scalar multiplication
3-element Vector{Int64}:
 2
 4
 6

一方，「全要素に同じ数を足す」は定義されていない． ベクトルとスカラーは 形が違う ので，そのままでは足せない． （@errmsg は，わざとエラーになる式の エラーメッセージだけ を短く表示する補助である．）

@errmsg [1, 2, 3] + 1    # vector plus scalar
MethodError: no method matching +(::Vector{Int64}, ::Int64)
For element-wise addition, use broadcasting with dot syntax: array .+ scalar
The function `+` exists, but no method is defined for this combination of argument types.

Closest candidates are:
  +(::Any, ::Any, ::Any, ::Any...)
   @ Base operators.jl:596
  +(::BigInt, ::Union{Int16, Int32, Int64, Int8})
   @ Base gmp.jl:550
  +(::Complex{Bool}, ::Real)
   @ Base complex.jl:323
  ...

そこで ブロードキャスト（演算子に . を付ける）を使う．. は 「スカラーを同じ要素数のベクトルとみなして，要素ごとに演算せよ」 という指示である．

[1, 2, 3] .+ 1           # treat 1 as [1,1,1] and add elementwise
3-element Vector{Int64}:
 2
 3
 4
重要峻別しよう（今回のかなめ）
  • スカラー × ベクトル 2 * xs … 許される（ベクトルの伸縮＝定義済み．ドット不要）．
  • ベクトル ＋ スカラー xs + 1 … ダメ（未定義）→ ブロードキャスト xs .+ 1．

「数どうしと同じようには書けない演算を，要素ごとにやりたい」ときに . を付ける．

重要予測しよう（L1）

[10, 20, 30] .+ 5 と 2 * [1, 2, 3] は何になるか，実行前に予想しよう．

[10, 20, 30] .+ 5
3-element Vector{Int64}:
 15
 25
 35

読み出しとスライス

ベクトルの 一部を取り出す には 添字 を使う． a[1] は1番目，a[end] は最後，a[2:3] は2〜3番目（スライス）．

重要予測しよう（L1）

下の a[end] と a[2:3] は何を返すか予想しよう．

a = [10, 20, 30, 40]
a[1]
10
a[end]
40
a[2:3]
2-element Vector{Int64}:
 20
 30

関数のグラフを描く

グラフを描くには，Plots パッケージ を使う．パッケージは using で読み込む （配布 notebook の先頭セルが，足りないパッケージをその場で導入する）．

using Plots
ノート

このノートブックでは，先頭の準備セルで using Plots と日本語フォントの設定を 済ませてある．自分で新しく書き始めるときは，最初に一度 using Plots を実行する．

x の値を 範囲 で作り，ブロードキャストで y を一気に計算 して plot(x, y) に渡すと， 関数 y = f(x) のグラフ（曲線） が描ける．

t = 0:0.5:3
y = t .^ 2          # square every element (broadcast); graph of y = x^2
plot(t, y)
重要予測しよう（L1）

plot(t[3:5], y[3:5]) は，曲線の どの部分 を描くか？

スライスすれば，曲線の 一部だけ を描ける．

plot(t[3:5], y[3:5])   # which part of the curve?

座標をつないで図形を描く

plot(xs, ys) は，2つの座標ベクトルの 同じ位置どうし (xs[i], ys[i]) を点とみなし， 順番に線でつないで いく．だから関数のグラフ（x が増える点列）だけでなく， 頂点を並べれば図形 も描ける．最後に 始点をもう一度 置くと，図形が閉じる．

重要予測しよう（L1）

下の xs，ys がつなぐのはどんな形か？ 点を順に (0,0) → (2,0) → (1,2) → (0,0) とたどると…？

xs = [0, 2, 1, 0]    # x coords of the vertices (last repeats the first to close)
ys = [0, 0, 2, 0]    # y coords
plot(xs, ys)

三角形が描けた．plot は「2つの座標ベクトルの点を順につなぐ」道具であり， 関数のグラフも図形も，同じ plot(横, 縦) の仕組みである．

ノート

ここでは アスペクト比（縦横の比）は指定しない．関数のグラフは縦軸と横軸で 意味が違うし，図形も今は形が分かれば十分だからである． 円や正方形を 正しい形（比） で見せる「アスペクト比＝1」は 第5回 で扱う．

今回のまとめ

  • ベクトル は複数の数のひとかたまり（エンティティ）．範囲 a:step:b で作れる．
  • スカラー倍 2 * xs は許される（定義済み）が，ベクトル ＋ スカラー xs + 1 はダメ → ブロードキャスト xs .+ 1（. で要素ごとに演算）を使う．
  • 添字・スライス（a[1]，a[end]，a[2:3]）で一部を取り出す．
  • 関数のグラフ は，範囲で x を作り broadcast で y を計算して plot(x, y)．スライスで曲線の一部も描ける．
  • plot(xs, ys) は 2つの座標ベクトルの点を順につなぐ：頂点を並べれば 図形（閉じるには始点を再掲）も描ける．
  • 関数のグラフでは アスペクト比は指定しない（図形を正しく見せる「アスペクト比＝1」は 第5回）．

  • plot … Plots.jl のドキュメント（日本語訳なし）
